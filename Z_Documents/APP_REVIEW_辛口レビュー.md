# Liftly アプリ 辛口レビュー

開発完了時点での総合評価：**使い勝手・UI/UX・差別化・ユーザー獲得可能性**について、READMEの目標（100ユーザー、初回体験成功率60%、D7継続20%）と「次のセットを最速で記録できる」というコンセプトを基準に評価する。

---

## 1. 総評：ユーザー獲得できるアプリか

**結論：土台はできているが、このままストアに出すと「もう一押し」で埋もれやすい。**

- **強み**：記録フロー（種目追加→セット入力→前回コピー→タイマー→完了）は一通り揃い、初回のオンボーディング（言語・単位→チュートリアル→最初の1本）も論理的。無料で使える範囲が広く、Proはクラウド同期と広告非表示に絞られており、試しやすい。
- **弱み**：「最速で記録」という差別化が**見た目・体感で伝わりきっていない**。ナビゲーションが「ホーム中心の深いプッシュ」のみで、**行きたい場所にすぐ行けない**。文言の不統一（ハードコード・日英混在）や、Proの価値が「同期＋広告削除」だけだと**人に勧める一言**が弱い。競合（Strong、Hevy、Fitbod等）と並べたときの「これを使う理由」がまだ弱い。

**100ユーザーを「口コミ＋ストア」で集めるなら、現状のままでも可能性はあるが、初回体験の成功（60%）とD7継続（20%）を狙うなら、以下の改善がほぼ必須。**

---

## 2. 使い勝手（UX）

### 良い点

- **ホーム→記録開始**：開始/再開ボタンが明確で、READMEの「2タップ以内」に近い。
- **セット入力**：重量・回数・時間・距離に対応し、前回コピー・タイマー統合で「トレ中にこのアプリだけで完結」する設計になっている。
- **初回フロー**：初期設定（言語・単位）→チュートリアル→最初のワークアウトまで一本道で、離脱ポイントが少ない。
- **履歴・種目別進捗**：カレンダー、種目別グラフ、メモ検索など、記録後に「見返す」動機が用意されている。

### 辛口で指摘したい点

1. **ナビゲーションが「ホーム依存」で重い**  
   履歴・全記録・種目一覧・メモ検索・タイマーがすべてAppBarのアイコンからプッシュ。よく使う操作（例：今日の履歴を見る、種目一覧から記録に飛ぶ）に至るタップ数が多く、「最速」の印象を損なう。タブやドロワーで「記録」「履歴」「設定」を分離するか、ホームにショートカットを増やす検討の余地あり。

2. **ワークアウト入力画面のタイトルが固定**  
   `AppBar` の `title` が `'Workout'` のままハードコード（l10n未使用）。日本語ユーザーには「ワークアウト」のまま表示され、他画面と表記が揃わない。

3. **初期設定画面の文言が未リソース化**  
   「Welcome to Liftly」「Language / 言語」「Weight / 重さ」等が直書き。READMEの「i18n：文字列は必ずリソース化」に反しており、言語切り替えしても英語が残る箇所がある。

4. **ツールチップ・文言のハードコード**  
   種目一覧の tooltip が `currentLanguage == 'ja' ? '種目一覧' : 'Exercises'` のようにコード内で分岐。同様の分岐が設定画面などに散在。l10nに寄せないと、文言追加・修正のコストと不整合が増える。

5. **エラー・空状態の扱いが弱い**  
   起動失敗やデータ取得エラーで「Error: $error」のような技術的な表示になりがち。一般ユーザー向けの「うまく読み込めませんでした。もう一度お試しください」＋リトライなどの配慮があると信頼感が増す。

## 3. UI/UX（見た目・一貫性・体感）

### 良い点

- **テーマ**：Material 3 ベースでプリセット＋カスタム色が選べ、アプリ全体で統一されている。
- **カード・ボタン**：ホームの統計カード、記録中カード、最近の記録など、情報の塊が分かりやすい。
- **チュートリアル**：スポットライト＋ツールチップで「どこを押すか」が明確。

### 辛口で指摘したい点

1. **「爆速」が視覚・コピーで伝わらない**  
   コンセプトは「次のセットを最速で記録」だが、ホームや入力画面にそれを主張する文言・ビジュアル（例：「前回を1タップでコピー」「セット入力はここだけ」）がほぼない。ストアや初回で「何が違うか」を一言で伝えるメッセージがあると差別化しやすい。

2. **ホームの情報がやや多め**  
   日付・今月の回数・ストリーク・体重・記録中/開始ボタン・最近の記録と、一画面に要素が多い。READMEの「1画面1目的」「視線誘導は縦で迷わせない」を考えると、**「今日やること＝開始/再開」**をさらに前面にしてもよい。

3. **入力画面の空状態**  
   種目未追加時は「種目を追加」が分かるが、「まずはここを押す」以外の励ましや、初回向けの短い説明があると安心感が出る。

4. **広告配置**  
   無料版でバナーが複数画面に出る。READMEの「記録を邪魔しない」に照らすと、**記録入力中・記録完了直後**には広告を出さないなどの配慮があると、体感が良くなる。

## 4. 魅力的な機能・差別化

### 良い点

- **前回コピー・種目別進捗**：同一種目の直近セッションを参照し、グラフで伸びが見られる。コンセプトの「前回が見える」「成長実感」に直結している。
- **休息タイマー**：バックグラウンド・通知対応で、アプリ切り替えを減らせている。
- **筋トレMemoインポート**：他アプリからの移行ニーズに応えられる明確な差別化。
- **クラウド同期（Pro）**：GoogleのみのSSOで、複数端末利用がしやすい。
- **日英対応**：en/ja の l10n が整っており、日本・英語圏の両方を狙える。

### 辛口で指摘したい点

1. **Proの価値が「同期＋広告削除」に集約されすぎ**  
   履歴・グラフ・テーマ・バックアップ等は実質無料で使えるため、有料化の動機が「クラウド同期が欲しい人」「広告が嫌な人」に限られる。READMEの「人に勧めやすい一言」を考えると、「Proにすると〇〇ができる」という**もう一つのはっきりしたベネフィット**（例：種目別目標・週次レポート・エクスポート強化など）があると、紹介されやすい。

2. **「記録が爆速」の証明がない**  
   機能としては前回コピー・タイマーで速さを支えているが、**体感や数字で示す**仕掛け（例：初回チュートリアルで「前回は1タップでコピーできます」と明言、または「3タップで1セット記録」のような一言）があると、ストア説明・口コミで使いやすい。

3. **競合との違いがストア・アプリ内で語られていない**  
   Strong / Hevy / Fitbod 等はテンプレート・プログラム・ソーシャル等で差別化している。Liftlyは「入力の速さ・前回コピー・タイマー統合」で差別化しているが、**アプリ内やストア文案でそれを明示している箇所がほぼない**。初見ユーザーには「普通の筋トレログ」に見えかねない。

## 5. ユーザー獲得の現実性（辛口まとめ）

| 観点 | 評価 | コメント |
|------|------|----------|
| 初回体験（→ 60%目標） | △ | 流れは良いが、「最速」の実感と文言の一貫性が足りない |
| 継続（D7 20%） | △ | 記録・グラフ・タイマーで理由はあるが、ホームの「今日やる」がもっと前面だと良い |
| 口コミ・紹介 | △ | Proの価値と「勧める一言」が弱い。差別化メッセージを明文化すると良い |
| ストアでの差別化 | △ | スクショ・説明文で「速さ・前回コピー・タイマー」を前面に打ち出せる |
| 技術・安定性 | ○ | ローカルDB、同期、l10n、テーマなど土台はしっかりしている |

**「このままでも100人なら届く可能性はある」が、「確実に届けて継続してもらう」には、以下が重要。**

1. **文言の統一**  
   初期設定・ワークアウト画面・ツールチップ等を l10n に寄せ、日英どちらでも一貫したメッセージにする。

2. **差別化の可視化**  
   ホームまたはチュートリアルで「前回1タップコピー」「セット間はタイマーで完結」などを短い文言で明示する。

3. **ナビの見直し**  
   履歴・種目一覧など頻出経路を、タブやホームのショートカットで「2タップ以内」に近づける。

4. **Proの価値の一言**  
   「クラウド同期＋広告なし」に加え、「〇〇ができる」というもう一つのベネフィットを決め、設定画面・ストアに書く。

5. **エラー・空状態**  
   技術用語を減らし、リトライやサポート導線を用意する。

---

## 6. まとめ

- **コンセプトと実装の方向性は一致している**（速さ・前回・タイマー）。機能の「有無」で見れば、MVPとして必要なものはそろっている。
- **弱いのは「伝え方」と「体感」**。差別化が画面やコピーに表れづらく、ナビと文言の細かい不整合が「もう一押し」を妨げている。
- 上記の改善（特に文言統一・差別化の明示・Proの一言）をすると、**100ユーザー獲得と、初回体験・継続の目標に届きやすくなる**。辛口に言えば「完成度は7割」だが、残り3割は**仕上げのUXとメッセージ**に集中すれば、ユーザーを獲得できるアプリに仕上がる。
