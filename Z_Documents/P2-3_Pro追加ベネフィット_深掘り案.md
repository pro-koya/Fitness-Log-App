# P2-3 Pro 追加ベネフィット 深掘り案

「種目別目標」「週次サマリ」「エクスポート強化」の 3 案を**有料にする価値がはっきり伝わる**ように深掘りし、3 つをまとめた「Pro 記録・成長パック」として設計する案です。

---

## 有料として弱く感じる理由の整理

| 案 | 弱く感じる理由 | 深掘りの方向性 |
|----|----------------|----------------|
| 種目別目標 | 「目標を書いておくだけ」だと無料メモでも代替可能 | **進捗の可視化**（あと〇〇で達成）と**達成時の祝福**で「アプリが伴走してくれる」体験にする |
| 週次サマリ | 月間サマリがすでに Free にあると「週も見れるだけ」に聞こえる | **週次目標**（例：週3回）と**前週比**で「今週の自分」を評価できる**週次レポート**にする |
| エクスポート強化 | 「PDF で出す」だけだと需要が限定的 | **レポートの自動送信**や**記録の形として残す・共有する**価値まで含めて「振り返りを習慣化する」機能にする |

→ 3 つを**ひとつのストーリー**にまとめると、有料の理由が伝わりやすくなります。

---

## 統一ストーリー：「目標 → 振り返り → 形に残す」

**Pro の価値の一言（案）**

- 「目標を立て、週で振り返り、記録をレポートとして残せる。成長を続けるための Pro 機能です。」

**ユーザー体験の流れ**

1. **目標**：種目ごとに「いつまでに〇kg / 〇回」を設定する（Pro）
2. **記録**：いつも通りセット記録。入力画面・種目別進捗で「目標まであと〇〇」が見える（Pro）
3. **振り返り**：週次サマリで「今週の回数・ボリューム・前週比」を確認。週次目標（例：週3回）の達成状況も表示（Pro）
4. **形に残す**：週次・月次レポートを PDF でエクスポート、または指定メールに自動送信（Pro）

Free は「記録と月間サマリ・種目別グラフ」まで。Pro は「目標設定 → 週次で振り返り → レポートで残す」まで、という線引きです。

---

## 1. 種目別目標（深掘り版）

### 現状のギャップ

- 種目別進捗画面（グラフ・履歴）は Free である
- 「目標」がないので「どこに向かっているか」が伝わりにくい

### 有料として価値が出る要素

| 機能 | 内容 | 有料らしさ |
|------|------|------------|
| **目標の設定** | 種目ごとに「目標タイプ」（重量 / 回数 / ボリューム / タイム / 距離）と「目標値」「期限（任意）」を 1 つ設定 | 設定 UI と永続化は Pro 限定 |
| **進捗の可視化** | 種目別進捗画面・入力画面（該当種目のセット行付近）に「目標まであと 〇kg / 〇回」または「達成率 〇〇%」を表示。プログレスリングやバーで表現 | 「アプリが目標を常に示してくれる」体験 |
| **達成の祝福** | 目標を達成したセッションでトーストや簡易アニメーション＋「〇〇の目標を達成しました」メッセージ。達成日を種目別進捗にマーク | ゲーミフィケーションで継続意欲を高める |
| **目標の履歴** | 目標を変更した場合でも「過去の目標値」を保持し、レポートや週次サマリで「当時の目標に対する達成率」を参照可能（Phase 2 でも可） | 長く使うほど「記録の意味」が増える |

### データモデル（案）

- テーブル: `exercise_goals`（`exercise_id`, `goal_type`, `goal_value`, `deadline_ts`, `created_at`, `updated_at`）
- `goal_type`: `weight` / `reps` / `volume` / `time` / `distance` のいずれか（種目の record_type に合わせて制限可）

### Pro ゲート

- 目標の**作成・編集・削除**は Pro のみ
- 目標**設定済み**の種目について、「目標まであと〇〇」「達成率」の**表示**も Pro のみ（Free は目標なしで従来どおり）

## 2. 週次サマリ・週次レポート（深掘り版）

### 現状のギャップ

- 履歴タブに**月間**サマリと週間トレンド（棒グラフ）はあるが、**週単位のまとまったレポート**はない
- 「今週はどうだったか」を一覧で見る・比べる体験が弱い

### 有料として価値が出る要素

| 機能 | 内容 | 有料らしさ |
|------|------|------------|
| **週次サマリ画面** | 選択した週の「トレーニング回数」「総ボリューム」「種目数」「前週比」（回数・ボリュームの増減%）を 1 画面で表示。既存の月間サマリと同様の指標を週単位で集計 | 「今週の自分」を数字で把握できる |
| **週次目標（オプション）** | 「週に〇回トレーニング」のようなシンプルな週次目標を 1 つ設定。週次サマリ画面に「今週 2/3 回」のように表示 | 習慣化の指標になる |
| **前週比・トレンド** | 「前週より +10% ボリューム」「連続〇週達成」などの短い文言を週次サマリに表示 | 成長実感・モチベーション |
| **週次レポートの PDF エクスポート** | 週次サマリの内容（日付範囲・回数・ボリューム・種目別サマリ・前週比）を PDF で出力。Pro 限定 | 「振り返りを形に残す」の第一歩 |

### 実装のつながり

- 履歴の `getWeeklyCountsForMonth` や SetRecordDao の月間集計を**週単位**にした API を追加（または既存を流用）
- 週は「月曜始まり」か「日曜始まり」を設定で切り替え可能にすると親切（l10n と合わせて）

### Pro ゲート

- **週次サマリ画面**（週選択・前週比・週次目標表示）は Pro のみ
- Free では「週次サマリは Pro で利用できます」のカードを履歴タブまたは一覧タブに表示し、タップで Paywall

## 3. エクスポート・レポート強化（深掘り版）

### 現状のギャップ

- バックアップ（JSON/CSV）は Free でも利用可能
- 「記録を人に見せる・自分用にレポートとして残す」という用途が弱い

### 有料として価値が出る要素

| 機能 | 内容 | 有料らしさ |
|------|------|------------|
| **PDF レポート** | 週次・月次のサマリ（回数・ボリューム・種目別・グラフの画像）を 1 枚〜数枚の PDF にまとめてエクスポート。日付範囲を選択して生成 | 記録を「形」として残せる |
| **レポートの自動送信（オプション）** | 毎週月曜 9:00 など、指定時刻に「先週の週次レポート」を PDF でメール送信。設定画面で ON/OFF・送信先メールアドレスを指定 | 振り返りを習慣化し、Pro ならではの体験に |
| **エクスポートの拡張** | 既存の CSV/JSON に加え、Pro 限定で「月次サマリ CSV」「種目別サマリ CSV」などテンプレートを追加してもよい（Phase 2） | データ活用の幅が広がる |

### Pro ゲート

- **PDF レポートの生成・保存・共有**は Pro のみ
- **自動送信**も Pro のみ
- 既存の JSON/CSV バックアップは Free のまま（データ保全は無料で提供）

## 4. 追加アイデア（有料感をさらに出す）

以下のいずれかを入れると、「アプリが考えてくれる」感が増し、有料の理由が伝わりやすくなります。

| 案 | 内容 | スコープ | 有料らしさ |
|----|------|----------|------------|
| **次の推奨重量・回数** | 種目ごとの直近履歴から「次は 〇kg × 〇回 を推奨」を算出し、ワークアウト入力画面のセット行付近や種目別進捗に表示。ロジックは単純（前回最大 +2.5kg や前回と同じ等）でよい | 小〜中 | 「アプリが提案してくれる」と感じられる |
| **目標達成バッジ・ストリーク** | 種目別目標達成時にバッジアイコンや短いアニメーション。週次目標の「〇週連続達成」をストリーク表示 | 小 | ゲーミフィケーションで継続意欲アップ |
| **週次レポートの自動送信** | 上記「3. エクスポート強化」に含めた「毎週〇曜に先週分の PDF をメール送信」 | 中（バックグラウンド・メール送信） | 「振り返りを忘れない」Pro ならではの価値 |

**推奨**  
- **次の推奨**：入力画面と相性が良く、「前回コピー」と合わせて「最速で記録」の差別化になる。  
- **目標達成の祝福**：種目別目標とセットで実装すると、目標の価値が伝わりやすい。  
- **自動送信**：週次サマリ・PDF 実装後に、余裕があれば追加。

## 5. Pro の価値の一文（ストア・アプリ内での使い方）

深掘り後の Pro を、次のように一言でまとめられます。

- **日本語（案）**  
  「目標管理・週次レポート・PDF エクスポートで、成長を記録に残せる Pro 機能です。」
- **英語（案）**  
  “Set goals, review weekly, and export reports—Pro features to keep your progress visible and lasting.”

設定画面の「Plan / Upgrade to Pro」と Paywall にこの一文を載せ、  
「種目別目標」「週次サマリ」「PDF レポート」の 3 つを箇条書きで補足すると、有料の理由が伝わりやすくなります。

## 6. 実装の優先順位とフェーズ

3 つすべてを実装する場合の目安です。

| フェーズ | 内容 | Pro ゲート |
|----------|------|------------|
| **Phase 1** | **種目別目標**（CRUD・進捗画面での「あと〇〇」・入力画面での表示・達成時メッセージ） | 目標の設定と「目標まであと〇〇」の表示は Pro のみ |
| **Phase 2** | **週次サマリ**（週選択・週次集計・前週比・週次目標「週〇回」・週次サマリ画面） | 週次サマリ画面全体を Pro のみ |
| **Phase 3** | **PDF レポート**（週次・月次のサマリを PDF で出力・保存・共有） | PDF の生成・保存・共有は Pro のみ |
| **Phase 4（任意）** | **次の推奨**（前回実績に基づく「次は〇kg」表示）／**目標達成バッジ**／**週次レポート自動送信** | いずれも Pro のみ |

- まず **Phase 1（種目別目標）** から着手すると、既存の種目別進捗・入力画面と密接に結びつき、ユーザーに「Pro で何が変わるか」が分かりやすいです。
- その次に **Phase 2（週次サマリ）** で「振り返り」、**Phase 3（PDF）** で「形に残す」と、ストーリーが揃います。

---

## 7. まとめ

- **種目別目標**：「目標を書く」だけでなく、**進捗表示**と**達成の祝福**まで含めて「伴走してくれる」機能にする。  
- **週次サマリ**：**週次目標**と**前週比**を入れた「週次レポート」にし、月間とは違う「今週の自分」を評価できるようにする。  
- **エクスポート強化**：**PDF レポート**と**自動送信（任意）**で「振り返りを習慣化し、記録を形に残す」価値にする。  
- 3 つを **「目標 → 振り返り → 形に残す」** の一連のストーリーとしてまとめ、**Pro 記録・成長パック**として提供する。  
- 追加で **次の推奨** や **目標達成の祝福** を入れると、有料としての説得力がさらに増します。

この深掘り案をベースに、Phase 1 の種目別目標から詳細設計（DB スキーマ・画面ワイヤー・FeatureGate）に落とし込んでいけます。
